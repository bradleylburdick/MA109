    Section 6.1 Solutions to a System of Equations

    Definition 6.1.1.

    A solution to an equation is a point \((x,y)\) that gives us a true statement when we plug in those values to the equation.
    🔗
    🔗

    Example 6.1.2.

    Let’s see if \((3,5)\) is a solution to the equation \(y=2x-1\text{.}\) In order to check, we will plug in \(x=3\) and \(y=5\) and see if we get something that’s true:
    🔗
    \begin{align*} y \amp= 2x-1\\ 5 \amp= 2(3)-1\\ 5\amp = 5 \end{align*}
    Indeed, \(5=5\) is a true statement, so \((3,5)\) is a solution to the equation.
    🔗
    🔗

    Checkpoint 6.1.3.

    Determine if each of the following is a solution to the equation \(2x+y=2\text{:}\)
    1. \(\displaystyle (2,-1)\)
      🔗
    2. \(\displaystyle (-2,6)\)
      🔗
    3. \(\displaystyle 4\)
      🔗
    🔗
    Answer.
    1. \((2,-1)\) is not a solution
      🔗
    2. \((-2,6)\) is a solution
      🔗
    3. \(4\) is not a solution
      🔗
    🔗
    🔗
    Solution.
    Determine if each of the following is a solution to the equation \(2x+y=2\text{:}\)
    1. \((2,-1)\text{:}\) In order to determine if this is a solution, we plug in \(x=2\) and \(y=-1\text{:}\)
      \begin{align*} 2x + y \amp= 2\\ 2(2) + (-1) \amp = 2\\ 3 \amp = 2 \end{align*}
      Of course, \(3 \neq 2\text{,}\) so we ended up with something that is not true. Therefore, \((2,-1)\) is not a solution to this equation.
      🔗
      🔗
    2. \((-2,6)\text{:}\) In order to determine if this is a solution, we plug in \(x=-2\) and \(y=6\text{:}\)
      \begin{align*} 2x + y \amp= 2\\ 2(-2) + (6) \amp = 2\\ 2 \amp = 2 \end{align*}
      Of course, \(2 = 2\text{,}\) so we ended up with something that is true. Therefore, \((-2,6)\) is a solution to this equation.
      🔗
      🔗
    3. \(4\text{:}\) Remember that a solution is a point, which includes two numbers. This is just a single number, so it cannot be a solution to the equation.
      🔗
      🔗
    🔗
    🔗
    🔗

    Definition 6.1.4.

    A system of equations is a set of more than one equation that we want to look at all at the same time.
    🔗
    🔗
    In this class, we will only look at systems of equations that have two equations and two variables. However, in later classes, you might look at more complicated systems that have more than two equations or more than two variables. In that case, you’ll learn more advanced techniques that can handle the more complicated situations.
    🔗

    Definition 6.1.5.

    A solution to a system of equations is a point that is a solution to all of the equations in the system at the same time.
    🔗
    🔗

    Example 6.1.6.

    Let’s determine if \((4,1)\) is a solution to the following system of equations:
    🔗
    \begin{equation*} \begin{cases}y \amp = x-3 \\ x - 4y \amp= 6\end{cases} \end{equation*}
    Just as we did before, we will plug in \(x=4\) and \(y=1\text{.}\) However, this time, we need to plug it into both equations and check that it works for both. Let’s start with the first one:
    🔗
    \begin{align*} y \amp = x-3 \\ (1) \amp = (4)-3\\ 1 \amp = 1 \end{align*}
    Now, let’s check the second one:
    🔗
    \begin{align*} x-4y \amp = 6 \\ (4)-4(1) \amp = 6\\ 0 \amp = 6 \end{align*}
    Since the point only worked for the first equation, but not the second, it is not a solution to this system of equations.
    🔗
    🔗

    Checkpoint 6.1.7.

    Suppose we have the system of equations:
    🔗
    \begin{equation*} \begin{cases} 3 \amp= 4x+y\\ -11 \amp= 2x+3y \end{cases} \end{equation*}
    Check if each of the following is a solution to the system:
    1. \(\displaystyle (1,-1)\)
      🔗
    2. \(\displaystyle (2,-5)\)
      🔗
    3. \(\displaystyle (-3,7)\)
      🔗
    🔗
    Answer.
    1. The point \((1,-1)\) is not a solution
      🔗
      🔗
    2. The point \((2,-5)\) is a solution
      🔗
      🔗
    3. The point \((-3,7)\) is not a solution
      🔗
      🔗
    🔗
    🔗
    Solution.
    1. To check if \((1,-1)\) is a solution, we plug it into both equations. Let’s start with the first equation:
      🔗
      \begin{align*} 3 \amp= 4x+y\\ 3 \amp= 4(1)+(-1)\\ 3 \amp= 4-1\\ 3 \amp= 3 \end{align*}
      That worked! Now, let’s check the second equation:
      🔗
      \begin{align*} -11 \amp= 2x+3y\\ -11 \amp= 2(1)+3(-1)\\ -11 \amp= 2-3\\ -11 \amp= -1 \end{align*}
      That one did not work. Since the point has to work for both equations in order to be a solution to the system, the point \((1,-1)\) is not a solution to this system.
      🔗
      🔗
    2. To check if \((2,-5)\) is a solution, we plug it into both equations. Let’s start with the first equation:
      🔗
      \begin{align*} 3 \amp= 4x+y\\ 3 \amp= 4(2)+(-5)\\ 3 \amp= 8-5\\ 3 \amp= 3 \end{align*}
      That worked! Now, let’s check the second equation:
      🔗
      \begin{align*} -11 \amp= 2x+3y\\ -11 \amp= 2(2)+3(-5)\\ -11 \amp= 4-15\\ -11 \amp= -11 \end{align*}
      That one also worked! Since it worked for both equations, the point \((2,-5)\) is a solution to this system.
      🔗
      🔗
    3. To check if \((-3,7)\) is a solution, we plug it into both equations. Let’s start with the first equation:
      🔗
      \begin{align*} 3 \amp= 4x+y\\ 3 \amp= 4(-3)+(7)\\ 3 \amp= -12+7\\ 3 \amp= -5 \end{align*}
      That did not work. At this point, we could plug it into the second equation, but that would end up just being a waste of time. It doesn’t matter if it works for the second one if we already know it doesn’t work for the first one. It has to work for both in order to be a solution, so the point \((-3,7)\) is not a solution to this system.
      🔗
      🔗
